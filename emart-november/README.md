# 이마트 고래잇 알뜰한 11월 장보기

PRD v0.2에 따른 모바일 중심 프로모션 웹페이지 시안입니다. 공식 emart 로고와 실제 이마트앱에서 확인한 색상값을 사용하며, 첨부 캠페인 이미지의 분위기를 반영했습니다.

## 주요 기능

- 센트럴점·파크점·리버점 선택에 따라 행사 3개 또는 4개 표시
- 식사 콤보, 주말 즉시 할인, 지정 가공식품 연계 구매, 리버점 퇴근길 행사
- 한국 시간 기준 시작·종료·요일·시간대 안내
- 행사 기간 안에서 날짜와 시간을 선택하는 방문일 미리보기
- 검증된 휴점일·영업시간을 우선하는 일정 처리와 미확정 안내
- 조건 펼치기, 질문과 답변, 공유, 모바일 하단 이동 버튼
- 웹 폰트와 최적화한 이미지 자체 제공, 외부 실행 라이브러리 없음

## 파일 구조

`dist/`를 정적 웹 호스팅의 문서 루트로 사용합니다. `index.html`, `styles.css`, `app.mjs`, `campaign.mjs`, `assets/`로 구성되어 있습니다.

`docs/PRD.md`는 기준 요구사항이며 `tests/campaign.test.mjs`는 일정 경계와 점포 필터, 마크업 연결을 검증합니다.

## 실행과 검증

Node.js 20 이상에서 추가 설치 없이 실행할 수 있습니다.

```sh
npm test
npm run check
```

페이지는 `dist/`를 정적 서버에서 제공하면 됩니다. ES 모듈을 사용하므로 `file://`로 직접 여는 방식보다 정적 호스팅을 사용하세요.

## 행사 설정

행사 기간과 점포별 설정은 `dist/campaign.mjs`에서 관리합니다. 실제 점포와 연결하기 전에는 `verified: false`를 유지합니다. 영업시간은 한국 자정부터의 분 단위이며, 휴점일은 `YYYY-MM-DD` 배열입니다.

식사 콤보는 종합 포스터의 월~목을 기준안으로 구현했습니다. 금요일 포함 여부, 세부 대상 품목, 할인 적용 금액, 행사 간 중복은 최종 확인이 필요합니다. 모든 할인은 행사 표시 상품에 한합니다. 실시간 재고, 쿠폰 발급, 실제 결제는 제공하지 않습니다.

## 디자인과 자산

이마트 공식 웹 로고, 이마트앱 공개 색상 변수, Noto Sans KR을 사용합니다. 제품·고래 이미지는 제공 포스터를 참고해 생성한 연출 이미지이며 실제 판매 상품을 확정하는 자료가 아닙니다. 출처와 폰트 라이선스는 `docs/ASSETS.md` 및 `dist/assets/NotoSansKR-LICENSE.txt`를 참고하세요.

이 페이지는 학습·검토를 위한 프로모션 기획 시안이며 실제 이마트 공식 행사와 다를 수 있습니다.
