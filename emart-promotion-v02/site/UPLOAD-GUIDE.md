# GitHub 웹 업로드 안내

이 ZIP은 빌드가 완료된 사이트입니다. npm 설치 없이 GitHub Pages에 올릴 수 있습니다.

1. ZIP 압축을 풉니다.
2. GitHub의 대상 저장소에서 Add file → Upload files를 엽니다.
3. 압축을 푼 폴더 안의 index.html, assets 폴더, images 폴더, favicon.svg, FONT-LICENSE.txt 등을 모두 올립니다.
   폴더 자체를 한 단계 감싸 올리지 말고, index.html이 저장소 최상위에 오도록 합니다. ZIP 자체를 업로드하는 방식은 아닙니다.
4. Commit changes를 누릅니다.
5. Settings → Pages → Build and deployment에서 Deploy from a branch를 선택합니다.
6. Branch: main, Folder: /(root)를 선택하고 Save를 누릅니다.
7. 배포가 끝나면 Pages 설정에 표시되는 실제 사이트 주소를 엽니다.

수정용 소스 ZIP은 별도입니다. 두 ZIP의 index.html은 역할이 다르므로 같은 루트에 함께 올리지 마세요.
행사 조건과 점포 정보가 일부 미확정인 검토용 페이지입니다. 공식 로고 서버 접근이 안 되면 일반 텍스트를 표시합니다.
원본 폰트 자산의 이용 조건은 FONT-LICENSE.txt를 확인하세요.
