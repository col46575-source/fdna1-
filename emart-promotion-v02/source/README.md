# 이마트 고래잇! · 11월 장보기

첨부된 「이마트 11월 프로모션 PRD v0.2」를 바탕으로 만든 한국어 반응형 프로모션 페이지입니다. React 19, TypeScript, Vite를 사용합니다.

## 실행

Node.js 24에서 검증했습니다.

```sh
npm ci
npm run dev
```

## 검증과 빌드

```sh
npm test
npm run test:e2e
npm run build
npm run preview
```

브라우저 테스트는 기본적으로 `/usr/bin/chromium`을 사용합니다. 다른 환경에서는 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`를 설치된 Chromium 경로로 지정하세요.

## 구현

- 최초 미선택 → 센트럴점·파크점 3개, 리버점 4개 혜택. 선택은 새로고침하면 초기화됩니다.
- `Asia/Seoul` 기준 2026년 11월 2일 00:00부터 11월 30일 00:00 직전까지 행사 일정을 안내합니다. 분 변경·화면 복귀 시 자동 갱신합니다.
- 상세 조건, 자주 묻는 질문, 유의사항, 공식 점포찾기와 기기 공유/링크 복사를 제공합니다.
- 모바일 하단 이동 버튼, 키보드 조작, 선택·펼침 상태, 모션 감소 설정을 지원합니다.

행사 데이터와 미확정 조건은 `src/data/campaign.ts`, 시간 판정은 `src/lib/schedule.ts`에서 관리합니다. 검증된 영업시간과 휴점 데이터가 입력되면 행사 시간 강조보다 우선 적용합니다. 현재 세 점포 정보는 미확정이며 영업·재고·실제 할인 가능 여부를 보장하지 않습니다.

## 공개 전 확인

현재는 **조건 확인 중인 검토용 시안**입니다. 콤보 요일·할인 대상 금액, 주말 제외 품목, 연계 구매 상품·산정 기준, 행사 간 중복, 실제 점포 ID·영업시간·휴점일을 확정해야 합니다. 결제·쿠폰·재고·분석 서비스는 연결하지 않았습니다.

헤더는 PRD에 지정된 공식 SVG 원본을 요청하며, 접근할 수 없으면 일반 텍스트로 점포 브랜드명을 표시합니다. 현재 클라우드의 네트워크 정책에서 `eappfront.emart.com` 접근이 차단되어 공식 로고 다운로드 검증은 보류 중입니다. 원본을 내려받아 배포 자산으로 포함하려면 해당 호스트 접근을 허용해야 합니다. 점포찾기는 PRD의 공식 주소로 연결하며 실제 점포별 매핑은 만들지 않았습니다.

고래·장보기 이미지는 이 구현을 위해 생성한 예시 일러스트입니다. 실제 공식 캐릭터나 행사 대상 상품을 의미하지 않습니다. Noto Sans KR은 Fontsource를 통해 자체 제공하며 라이선스는 설치 패키지에 포함되어 있습니다.

## GitHub 웹 업로드

사이트 업로드용 ZIP은 이미 빌드한 정적 웹페이지입니다. 압축을 풀어 `index.html`, `assets`, `images`, `favicon.svg` 등을 저장소 최상위에 업로드하세요. GitHub의 **Settings → Pages → Deploy from a branch → main → /(root) → Save**를 설정하면 별도 Node.js 서버 없이 게시할 수 있습니다. ZIP 자체를 올리는 방식은 아닙니다.

소스 ZIP은 수정·개발용입니다. 소스를 GitHub Pages에서 게시하려면 `npm ci`와 `npm run build`를 실행한 후 `dist` 안의 파일을 게시하세요. 두 ZIP은 같은 저장소 루트에 함께 올리지 마세요. Vite의 상대 경로 설정으로 저장소 이름이 붙은 GitHub Pages 주소에서도 자산을 읽을 수 있습니다.
